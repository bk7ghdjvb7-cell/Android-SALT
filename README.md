# Android SALT

Android app for Savannah Area Local Tours.

Open this folder in Android Studio, or build the debug APK with Gradle. The app uses Android SDK 34.

Demo sign-in: `demo@salt.savannah` / `SavannahTour1`

Any email containing `@` and any password of at least 12 characters signs in. Five failures for the same email lock that email on the device for 15 minutes.
